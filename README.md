# ESP32 to ThingSpeak

This is my IoT homework project using ESP32 and DHT22 sensor.

The sensor reads temperature and humidity and sends the data to ThingSpeak using Wi-Fi. The data is displayed in two charts.

## Tools Used

- ESP32
- DHT22
- Wokwi
- ThingSpeak
